# 📘 فكرة برنامج منارة

برنامج **منارة** هو نظام بسيط لمراكز تحفيظ القرآن الكريم، يهدف لتسهيل إدارة الطلاب وتتبع تقدمهم اليومي.  
يسمح للمشرفين بتسجيل بيانات الطلاب، تحديث الحفظ والمراجعة، تسجيل الغياب، وعرض سجل كامل لكل طالب.

---

## ⭐ ماذا يقدم البرنامج؟
- تسجيل طالب جديد مع بياناته الأساسية.
- تعديل بيانات الطالب ومتابعة تاريخ التعديلات.
- تسجيل الحفظ والمراجعة اليومية.
- رصد الغياب والحضور.
- عرض قائمة الطلاب بطريقة منظمة وبحث سهل.

---

## 🛠 التقنيات المستخدمة
يعتمد المشروع على تقنيات ويب بسيطة وسهلة:

- **HTML / CSS / JavaScript**
- **jQuery** للتعامل مع الواجهة (DOM & Events)
- **LocalStorage (JSON)** لحفظ البيانات محليًا بدون إنترنت
- **Firebase Realtime Database** لمزامنة البيانات وتخزينها سحابيًا
- **Firebase Hosting** (اختياري للنشر)

---

## 🎯 الهدف العام
توفير نظام يساعد مراكز التحفيظ على إدارة طلابها بشكل أسهل وأسرع، ويقلل الاعتماد على الدفاتر التقليدية.

> البرنامج ما يزال **قيد التطوير**، وسيتم إضافة ميزات جديدة لاحقًا.
